# Avatar assets

Place `welcome.mp4` and `explaining.mp4` in `apps/web/public/videos/`. These are provided and already copied. Welcome plays once per tab session; explaining plays once when Projects first enters view. Optional expression stills belong in `apps/web/public/images/` using `avatar-idle.png`, `avatar-thinking.png`, `avatar-listening.png`, `avatar-talking-open.png`, and `avatar-talking-closed.png`. Missing optional files are handled without breaking the app.
